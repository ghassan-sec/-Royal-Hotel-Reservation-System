🏨 Royal Hotel Reservation System
Description

This project is a simple Hotel Reservation System developed using Python. The program allows customers to book hotel rooms by selecting a room type and specifying the number of nights they wish to stay. It then calculates the total accommodation cost and generates a booking invoice.

The system begins by welcoming the customer and requesting their name. After that, the customer chooses a room type from the available options: Normal or Suite. The customer also enters the number of nights for their stay.

Based on the selected room type, the program assigns a nightly rate. A Normal room costs $50 per night, while a Suite costs $100 per night. The total price is then calculated automatically by multiplying the room rate by the number of nights booked.

Finally, the system displays a detailed invoice that includes the customer's name, room type, number of nights, and total amount to be paid. This project is an excellent example of using basic Python concepts to create a simple hotel booking application.
